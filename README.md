# Cosmistic_2 — Oliveco

A responsive, bilingual product catalogue for Olive Marketing Group Co., Ltd.

The application lives in [`oliveco/`](oliveco/). The `working-version1` tag marks the first working snapshot, including the updated “Shop” navigation label.

## Run locally

Install Node.js 22 or newer, then run from the repository root:

```sh
npm --prefix oliveco ci
npm --prefix oliveco start
```

Open http://localhost:4173.

## Check

```sh
npm --prefix oliveco run check
```

See the [application README](oliveco/README.md) for features, product prices, and optional server-side AI configuration.
